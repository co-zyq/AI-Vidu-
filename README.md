# AI 创作网页自动化控制台（Vidu / 即梦）

本地 Web 控制台，用浏览器自动化批量操作两个 AI 创作网页：

- `app.py` — Vidu 图生视频：多张图片 + 统一提示词 → 批量生成视频
- `jimeng_app.py` — 即梦图生图：上传图片 → 按提示词生成图片

两个控制台共用同一套设计：上传图片、统一提示词、任务队列依次执行、单浏览器窗口常驻、完成后自动下载到本地、支持取消任务。

## 环境准备

需要 Python 3.12：

```
python3.12 -m venv .venv
.venv/bin/pip install flask playwright
.venv/bin/python -m playwright install chromium
```

## 启动

Vidu 视频控制台：

```
PORT=5005 .venv/bin/python app.py
```

打开 http://127.0.0.1:5005

即梦图片控制台：

```
.venv/bin/python jimeng_app.py
```

打开 http://127.0.0.1:5001

端口默认分别为 5000 / 5001，可用环境变量 `PORT` 修改。

## 首次使用：登录一次

- Vidu：提交任务时浏览器会打开，若未登录任务会提示；在弹出的浏览器窗口登录 Vidu 后重新提交即可（登录态保存在 `browser_profile/`）
- 即梦：点控制台上的「登录即梦」，在弹出的浏览器窗口扫码或手机号登录；窗口会一直保留，登录后不用再点

## 任务流程

1. 在网页上传图片（可多选），填写统一提示词，点「提交任务」
2. 任务按提交顺序严格排队，共用同一个浏览器窗口：前一个生成并下载完成，才开始下一个
3. 程序会确认“生成已开始”后才等待结果，完成后自动下载到本地目录（Vidu：`downloads/`；即梦：`jimeng_downloads/`）
4. 生成过程中如果出现弹窗，可以手动关闭，程序会继续等待

## 运行时生成的目录

以下目录是运行时自动生成、包含你的个人数据，**不要提交到代码仓库**：

```
browser_profile/          # Vidu 浏览器登录态
browser_profile_jimeng/   # 即梦浏览器登录态
uploads/                  # 上传的图片
downloads/                # Vidu 生成的视频
jimeng_downloads/         # 即梦生成的图片
```
